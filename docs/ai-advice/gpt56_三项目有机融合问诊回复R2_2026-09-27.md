6. 所有 generated 产物的统一哈希登记

每个主要 generated artifact 配同名 receipt：

<artifact>.receipt.yaml

例如：

generated/index/tasks.json.receipt.yaml
generated/index/evidence.json.receipt.yaml

receipt 固定五项：

source: ["repo/relative/a","repo/relative/b"]
source_sha256: <bundle sha256>
projection_sha256: <actual artifact raw bytes sha256>
generator_version: <generator git/blob/code hash>

实际 YAML 中 source 的值是一行内联 JSON，不嵌套。

算法锁死：

source_sha256 = SHA256(sorted(source_ref + NUL + raw_source_sha256).join(LF))

build_id = first20hex(SHA256("fusion-v1" + NUL + artifact_path + NUL + source_sha256 + NUL + generator_version))

projection_sha256 = SHA256(生成文件最终 UTF-8/LF/末尾单换行的实际字节)

重要：receipt 不写入被 hash 的 artifact 本体，否则产生自引用 hash；receipt 自身不递归要求另一份 receipt。

两个 GENERATED project.yaml 也按同样规则登记 receipt。

Gate 规格与 6 个 canary

统一机器输出格式：

GATE|<gate>|PASS|...

或：

GATE|<gate>|FAIL|reason=<code>|object=<id>|source=<ref>|detail=<short-text>

任何 Gate 都必须把第一条失败打印成一行，人一眼能看到；可以随后打印更多失败。

统一内部错误退出码 2；业务 Gate 用各自唯一非零码。

Task Authority Gate

runners/authority-check.mjs

∀ logical_task_id: count(writable_authority_source) = 1

status(§八) = forbidden

Learning Coverage Gate

TriggeredEvidence = {e | e.learning_trigger == "true"}
