## 三、核心设计（16 条宪法精华）
1. **Memory = Global Kernel + Project Namespace + Layered Retrieval + Quarantined Ingress**
2. **Routing before Retrieval**：先定项目再读记忆；**Multi-read / Single-write**；**Fail Closed**（定不了就拒绝，绝不猜）。
3. **项目隔离**：projects/<id>/ 物理隔离，Agent 默认只读 global + 自己项目。
4. **稳定 ID**：S-ID（状态）/ D-ID（决策），消失必须 DROP 声明（hook 机械拦截）。
5. **分层记忆**：L0 工作记忆（不落盘）→ L1 隔离暂存（inbox，允许 UNKNOWN）→ L2 项目 STATE → L3 DECISIONS/CHANGELOG/archive。
6. **隔离记忆（v2.1）**：对话中产生的候选事实先 capture 到 inbox（project_hint 可 UNKNOWN），settle 时定项目正式写入；UNKNOWN 不等于 global，普通 Agent 不读全量。
7. **防膨胀**：STATE ≤60 行/12KiB/完成 8 条；CHANGELOG 200 条归档；DECISIONS 80 条归档；STALE 只复核不自动删。
8. **安全**：凭证值绝不入记忆；capture 落盘前 secret preflight；key rotation 而非删历史。
9. **模型无关**：记忆是纯文本 + git + 脚本，任何模型读 RULES+STATE 即可接手，切换模型零成本。
