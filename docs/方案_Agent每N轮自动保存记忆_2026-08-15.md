# 方案：Agent 每 N 轮自动保存记忆（防跨会话记忆丢失）

> 状态：方案稿（2026-08-15）｜目标：换 Agent / 新会话不丢记忆
> 配套：ai-hub-memory 记忆系统 v2.1（memory.py + RULES 16 条宪法）

## 1. 目标

- 已有项目：用户新开会话 → Agent 读该项目记忆 → 被注入「每 ~10 轮自动保存一次」规则 → 干完一部分活自动落记忆，明天接着干不丢。
- 新项目：用户说过一次「存记忆」后 → Agent 一访问该项目记忆线即被注入同一规则。
- 换 Agent / 跨会话：接手的 Agent 读到上一份交接记忆，无缝衔接。

## 2. 现状（已有什么）

| 能力 | 现状 |
|------|------|
| 启动注入点 | AGENTS.md「任何 Agent 接手任务前先读它」✅ |
| 行为注入点 | memory-router/SKILL.md「读写记忆前必须加载」✅ |
| 写记忆通道 | memory.py write / capture / sync ✅ |
| 项目路由 | MEMORY.json + R1'~R16 ✅ |
| 防覆盖 | git pull --ff-only + 单写者 + pre-commit 守卫 ✅ |
| **缺** | 「每 N 轮自动保存」的**注入规则**与**机制强制** ❌ |

## 3. 方案：三层

### 3.1 提示词注入层（软约束，零改造，立即生效）
在 RULES.md「读写时机」加一条 **R18「自动保存节奏」**（或在 AGENTS.md 注入段加）：
> 每完成约 10 轮对话，主动检查一次：是否产生值得保存的阶段成果（可交付 / 拍板决策 / 状态变化 / 其他 Agent 需要的事实）。有 → 用 memory.py write 写入本项目；无 → 跳过。会话结束或被交接前，必须写一条「阶段交接」记忆（S-<日期>-<序号>）。

效果：所有读记忆的 Agent（Claude Code / ChatGPT / 执行 Agent / DSH）都被注入，因它们都读 AGENTS/RULES。

### 3.2 机制强制层（硬保证，按平台）
| 平台 | 做法 | 可靠性 |
|------|------|--------|
| DSH（DeepSeek Harness） | agent-loop 加「每 N 轮记忆检查」插件/事件（轮次计数到 10 触发一次记忆快照动作） | 确定性 ✅ |
| Claude Code | 用 hooks（Stop 等）或 memory MCP 自动触发写入（外部已有 claude-hooks 等先例） | 高 ✅ |
| 纯网页对话 Agent | 无法加 hook → 只能靠 3.1 提示词层 | 软约束 |

### 3.3 防污染设计（关键）
- 每 10 轮是「**检查 + 提醒**」，不是「无脑写」——有可交付成果才写，中间过程不写（呼应 R13「值不值得成为正式记忆」）。
- 写前判断归属：已注册项目直接写；全新项目 register；拿不准 capture（呼应 R1'/R7）。
- 自动写不绕过 Fail Closed：scope 不明就 capture 到隔离区，不猜。

## 4. 实施步骤（按成本递增）

1. **RULES.md 加 R18（提示词注入）** —— 零风险，立即对所有读记忆的 Agent 生效。
2. **AGENTS.md / memory-router SKILL 同步引用** —— 保持单一真源在 RULES。
3. **验证**：模拟一次会话，确认注入规则出现在 Agent 读到的内容里。
4. （可选）**DSH 插件**：agent-loop 每 N 轮记忆快照，对 DSH Agent 硬保证。
5. （可选）**Claude Code hooks**：为跑在 Claude Code 的 Agent 配自动写 hook。

## 5. 风险与对策

| 风险 | 对策 |
|------|------|
| LLM 数轮次不可靠（软约束层） | 3.2 机制层兜底；提示词写「约 10 轮」而非精确计数 |
| 过度写入污染记忆 | 3.3 检查式设计；单条 ≤600 字；CHANGELOG 可回溯 |
| 多 Agent 并发写 | 已有 R5 单写者 + pull --ff-only + pre-commit 守卫 |
| 自动保存触发时无成果 | 跳过并继续，不产生空记录 |

## 6. 验收标准

- [ ] 新会话 Agent 读项目 STATE 后，能看到「每 ~10 轮自动保存」规则（注入生效）
- [ ] 连续对话约 10 轮后，Agent 能主动产出 S-ID 记忆条目（write 到正确项目）
- [ ] 换 Agent 后，新 Agent 能读到上一条「阶段交接」记忆并继续
- [ ] 无凭证泄漏（pre-commit secret guard 全绿）
