- [D-20260814-01] # 英语学习策略决策（用户拍板）

1. 前期目标：至少刷到3000词，通过翻译高质量文本快速筛出大部分不认识的词（筛词模式）。
2. 学习形式：以翻译有难度的高质量文本为主（外刊/VOA/主题短文），通过翻译暴露陌生词，主动回忆词义+构造句意。
3. 复习规则：消退提示法6轮（R1四选一→R2三选一→R3中译英二选一→R4无选项英译中→R5无选项中译英→R6语境运用）；FSRS动态间隔；答错退回上一轮；连续2次Again重R1。
4. 批量规则：复习类测试每次至少20个起步；学新内容每次至少10个起步。
5. 轮次必须按记忆曲线间隔（R1后隔天R2），禁止同日连续做下一轮。
6. 选项位置必须打乱，禁止正确答案固定同一位置。（2026-08-14）

- [D-20260814-02] # 英语学习用户偏好（重要）

1. 反感被反复询问理所当然的决定；AI应主动推断并直接执行默认动作（记词、纳入复习队列、继续下一篇），不打断学习流程。
2. 喜欢翻译有难度的文本（主动回忆词义+构造句意），反感孤立造句（无聊、编不下去）。
3. 错词必须展示音标（用户可能读不好）。
4. 学习节奏：每天约30-60分钟对话，约3-6篇翻译文本强度，备考强度为考研英语一的一半。
5. 兴趣是最好的老师：保持学习流程连贯，AI主动给出下一步方向，不让流程断开。
6. 用户会直接批评错误（如选项全放A、同日连续复习），需认真对待并改进。（2026-08-14）
