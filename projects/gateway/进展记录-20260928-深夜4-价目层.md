## 2. 代码落点

- `services/price_pages.py`（新）：8 个渠道的页面表 + 7 个解析器（groq freeRows / gemini Free Tier / mistral 单元格 / siliconflow 徽章 / cloudflare neuron 表 / nvidia 卡徽章 / longcat ¥ 价 / typesafe openapi）。纪律：抓到 0 价才 free，抓到非 0 才 paid，页面上查无 → unknown，绝不外推。读页面一律不带 key；先代理后直连；空壳页重试 3 次（半张页面比读不到更坏）。
- `services/channel_profiles.py`：新增 `price_page` 判据类与 `DISABLED`（整档停用，区别于封存）；gemini / groq / cloudflare / nvidia / longcat / mistral / typesafe 从 site_terms·unknown 升成 price_page 并写明 basis；modelscope / agnes 的 basis 改成"为什么判不了"。
- `scripts/channel_free_audit.py`：价目页接进逐模型判定（`priced_by_page` 留每行依据 + URL）；新增报表段⑦（每渠道一行：已补判据 / 对不上 / 查不到 / 不走页面）、⑧（非 0 价席位单独成段）；沙盒 `--offline/--fixture` 零请求零落盘，价目页另有 `--fixture-price` 假表。
- `scripts/auto_orchestrate.py`：消费当日 `channel_free_models.json` 的价目页结论 → `auto_remove_nonzero_price`（code=`price_page_nonzero`），并同样作用于旧别名免费链（口径不因链旧而豁免）；ADD 侧与纯快线取数池同一道闸；快照不是当天 → `PRICE_PAGE_STALE`，不按旧结论动今天的编排；决策台账 DELETE 行新增 `evidence` 字段，把页面原话存进去。
