# MEMORY.md — 英语教学 稳定知识（长期语义记忆）

> 定位：本文件回答「关于这个项目，我们已经确定了什么」，不回答流水账。
> 与 STATE.md 的分工：STATE 回答「现在发生什么、下一步是什么」；MEMORY 回答「已确定的知识」。
> 与 ROUTER.md 的分工：ROUTER 是低语义路由索引（历史在哪里），MEMORY 是已提炼的稳定结论。
> 维护：只有当某条经验被**多次**验证、或属架构级决定时才写入本文件；单次事件留在 STATE。

---

## 一、教学对象与交付架构（两条学生线）

1. **谭雨欣线（2026 中考）**：核心题型 = 强化选词填空 10 选 10 带词形转换 + 阅读回答问题 5 问规范简答。讲义架构 = 复习旧语法 60% + 学习新语法 40%。
2. **王程线（小升初分班考）**：全真 5 大标准题型 = 单项选择 10 + 词形转换 8 + 句型转换 8 + 单句改错 6 + 篇章选词填空 8 = **40 题满分卷**；严控 ≤40 题/课。
3. 每课材料固定三件套：**学生版 + 教师版 + 写作专项**（写作专项仅双数课次，作文闭环）。

## 二、讲义规范

1. **第 1 面 = 系统语法全景图**，第 2 面 = 全真分班考题型实战；主观/改错/转换/翻译类题占比 70%+（课前温故 12 + 新知精练 20 + 微语篇 8 空）。
2. 课时大纲先行：第 1-3 课可已结课，后续课按「全景大纲 → 逐课讲义 → 写作专项」推进。
3. 输出格式 = **Word (.docx)**；生成后清理散落的 .md 冗余文件。

## 三、归档规范（文件组织）

1. **每课独立专属主题子目录**，根目录只保留全景大纲及词汇筛选库。
2. 配套练习按【第01天】~【第10天】独立主题子目录归档，内含讲练版与基础练习版（各含学生版+教师版）。
3. 落盘路径固定：谭雨欣 = `D:\英语教学\谭雨欣\`；王程 = `D:\英语教学\王程\`。
4. 清理过时冗余：根目录散落的旧【学生版】【教师版】重复文件夹及重复文件一律清除，保持结构单一。
