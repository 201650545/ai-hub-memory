- **[S-20260815-05]** # Python 生成器中文字符串含 ASCII 双引号的坑（必读）

在 DOCX 生成器（python-docx）中给中文释义/讲解写字符串时，**中文语境里的引号若误用 ASCII `"` 会直接破坏 Python 字符串边界**，导致 SyntaxError。

## 症状
- 报错 `SyntaxError: invalid character '，' (U+FF0C)` 等，位置指向中文长字符串内部，看似是逗号问题，实则是引号提前闭合了字符串
- 一次 Edit 塞入大量含引号的中文数据（如完形 15 题解析）时极易中招

## 铁律
1. **中文文本内一律用中文引号「」或""（U+201C/U+201D），绝不写 ASCII `"`**
2. 例句需引号时用「」最安全：`「If you elect me president,」 she shouted` → 释义写 `「如果你们选我当主席，」她大声喊道`
3. 若已经写坏：**不要用正则/状态机自动替换**（会误伤 Python 字符串边界），直接整块重写该数据段（Write 到临时文件 → Python 读入按 marker 替换 → ast.parse 校验后写回）
4. 修复后必须 `ast.parse` 或 `compile()` 校验语法再生成
