## 3. 缺口与两个待选方案（评审重点①）

v2.8 只监听了"报错"。工具调用 / 长推理 / 任务完成三个事件源缺失。

- **案 A（纯前端 observer）**：扩展现有 MutationObserver，按节点 class/文本特征识别工具调用块、长时间无输出的 thinking 态、任务完成徽记。零后端改动，当天可上；识别精度受 DSH 前端 DOM 结构约束，DSH 改版可能失效。
- **案 B（server 事件流）**：DSH 插件 `pkg/src/index.ts` 增加事件 hook（若 harness 有 tool/error 生命周期钩子）→ `/api/nitian/event` 落盘 → 客户端随 poll 顺带读取。事件可靠、语义精确；但要动 server 侧代码（需单独授权）且依赖 harness 是否暴露钩子。
- 默认建议：**先 A 后 B**——A 上线跑两周，若误报/漏报率高再上 B。理由：v3 样板阶段验证的是"叙事层"不是"事件采集精度"，粗粒度事件足以支撑回响演出。

## 5. 四进度窗（元婴期具体化）

窗口只由 **当前境界 Token 进度 pct** 驱动（内部导演参数，不展示给用户）：

| 窗口 | pct | 世界变化（永久感） | 用户感知 |
|---|---|---|---|
| 入世 | 0–30% | yuanyingCG 背景渐显替代通用底；era_04 分身立绘入场；时代名浮现 | "到了新地方" |
| 因起 | 30–65% | 卷轴边角点亮人物/法宝标签；远处云天宗剪影 | "这卷故事在展开" |
| 劫至 | 65–90% | 敌人池切换为藤家系；海报压暗频率上升；语录偏移到复仇线 | "要变天了" |
| 临界 | 90–100% | 常驻克制异象：境界印呼吸加快、仙玉环微震、裂纹微光 | "马上破境"但**不弹窗、不遮代码、可正常干活** |

红线：修为只升不降 ⇒ 世界只向前。窗口跃迁不可逆，离线多天后恢复 = 直接落在当前 pct 对应窗口，不重放。

## 7. 破境三连接（enter 不动，前后加拍）

1. **破境前**：临界窗异象随 pct→100 渐强（克制、无 modal）
2. **enter(5)**：现有全屏演出原样
3. **Aftermath 余韵（新增，~6s，Esc 可跳）**：视频结束不清场 → era_05 海报首次完整展开 + 时代名"神游太虚 · 生死意境" + 元婴卷盖"已历"印 + 化神卷只露第一条线索 → 淡出回到 coding
